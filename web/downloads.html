Every app download includes the desktop app and the CLI. Latest release: v0.5.0.

Choose your operating system and processor. Apple silicon Macs and 64-bit ARM systems use ARM64. Intel and AMD computers use x64.

Check the file's SHA-256 with the command under each download. On macOS, open the .dmg and drag Capturefab to Applications. For a .zip download, extract it and move Capturefab.app to Applications. On Windows and Linux, extract the archive before you open the app. The first-launch steps cover the permission prompts each system shows.

Read the installation instructions for system requirements, command-line setup and use without a display.

Install from a terminal

One command downloads the build for this computer, checks its SHA-256 and installs it for your account, without sudo or administrator rights.

macOS and Linux

curl -fsSL https://capturefab.com/install.sh | sh

Installs Capturefab.app in ~/Applications on macOS, or the release folder in ~/.local/share/capturefab on Linux, and links capturefab in ~/.local/bin.

Windows PowerShell

irm https://capturefab.com/install.ps1 | iex

Installs in %LOCALAPPDATA%\Programs\Capturefab, adds it to your user PATH and adds a Start menu shortcut.

To read a script before it runs: curl -fsSLO https://capturefab.com/install.sh; less install.sh; sh install.sh. Add --dry-run (-DryRun for install.ps1) to print the file, URL and checksum it would use. Read install.sh or install.ps1.

Source code

Capturefab uses the MIT license. Each release publishes its source as a download: the exact Capturefab files and every Rust dependency, ready for an offline build.

capturefab 0.5.0 source

Download capturefab-0.5.0-source.tar.gz ↓

123.8 MiB · SHA-256 9a73b26574baf03fc76d853ee40d0c7e537b89473cc55ce686ad5940632a8a7c

Use a stable Rust toolchain, a C compiler and CMake. For x86 builds, NASM is necessary for libjpeg-turbo. A release build also builds FFmpeg from pinned upstream archives when it has no copy. Read the FFmpeg build guide for that step. On macOS, use shasum -a 256 -c in place of sha256sum -c.

echo "9a73b26574baf03fc76d853ee40d0c7e537b89473cc55ce686ad5940632a8a7c  capturefab-0.5.0-source.tar.gz" | sha256sum -c
tar -xzf capturefab-0.5.0-source.tar.gz
cd capturefab-0.5.0
cargo --config .cargo/vendor-config.toml build --release --offline --locked
target/release/capturefab --camera sim:0 capture -o first.png
