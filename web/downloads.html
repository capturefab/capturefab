All downloads

Each download is the capturefab command-line tool for one system, with FFmpeg built in. Latest release: v0.6.1.

Choose your operating system and processor. Apple silicon Macs and 64-bit ARM systems use ARM64. Intel and AMD computers use x64.

Check the file's SHA-256 with the command under each download, then extract the archive and put capturefab on your PATH, or use the install command below, which does both. The first-launch steps cover the permission prompts each system shows.

Read the installation instructions for system requirements and setup on computers without a display.

Install from a terminal

One command downloads the build for this computer, checks its SHA-256 and installs it for your account, without sudo or administrator rights.

macOS and Linux

curl -fsSL https://capturefab.com/install.sh | sh

Installs the release folder in ~/.local/share/capturefab and links capturefab in ~/.local/bin.

Windows PowerShell

irm https://capturefab.com/install.ps1 | iex

Installs in %LOCALAPPDATA%\Programs\Capturefab and adds it to your user PATH.

To read a script before it runs: curl -fsSLO https://capturefab.com/install.sh; less install.sh; sh install.sh. Add --dry-run (-DryRun for install.ps1) to print the file, URL and checksum it would use. Read install.sh or install.ps1.

Source code

Capturefab uses the MIT license. Each release publishes its source as a download: the exact Capturefab files and every Rust dependency, ready for an offline build.

capturefab 0.6.1 source

Download capturefab-0.6.1-source.tar.gz ↓

37.6 MiB · SHA-256 8e1f8d9b0b6898f89911778cf45d0343b3e8ea0c8265c0ddbd99584ec468f95a

Use a stable Rust toolchain, a C compiler and CMake. For x86 builds, NASM is necessary for libjpeg-turbo. Cargo does not build FFmpeg: build it with scripts/build-ffmpeg.sh and set CAPTUREFAB_FFMPEG_BINARY to embed it, or Capturefab uses CAPTUREFAB_FFMPEG, or an ffmpeg beside it or on PATH, when it runs. Read the FFmpeg build guide for that step. On macOS, use shasum -a 256 -c in place of sha256sum -c.

echo "8e1f8d9b0b6898f89911778cf45d0343b3e8ea0c8265c0ddbd99584ec468f95a  capturefab-0.6.1-source.tar.gz" | sha256sum -c
tar -xzf capturefab-0.6.1-source.tar.gz
cd capturefab-0.6.1
cargo --config .cargo/vendor-config.toml build --release --offline --locked
target/release/capturefab capture -c sim:0 -o first.png
