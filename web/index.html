The camera workbench for machine vision, and every other camera.

Discover, configure, capture and record from GigE Vision and USB3 Vision cameras, webcams and network streams. A native desktop app and a scriptable CLI in one self-contained binary, with no vendor SDK to install.

Features

Everything between the sensor and the file.

The GigE Vision, USB3 Vision and GenICam stack is written in Rust. Webcams, streams, decoding and encoding use a bundled FFmpeg executable. Nothing else needs to be installed.

Industrial cameras, natively

GVCP/GVSP and U3V with live GenICam feature trees, packet resend and loss counters. No Aravis or vendor SDK.

capturefab discover

Webcams and streams

Built-in and USB webcams, HDMI capture cards, ONVIF discovery, RTSP, SRT and video files.

capturefab native

Auto exposure and frame rate

Opt-in per camera. Balance image quality against frame rate; it backs off on packet loss and can revert.

auto --balance 0.25

Capture now, later or on a schedule

Delays, intervals and timelapses with explicit timezones. Jobs report progress and can be cancelled.

capture --interval 10s

Record and forward

Record MKV or MP4, or publish to MediaMTX, an NVR or SRT. Hardware encoders are probed before use, with a software fallback.

forward --encoder auto

External drives and S3

Save to folders, removable drives or S3-compatible buckets. Secrets stay in the OS keychain and objects are never replaced.

--destination archive

Storage that can't run away

A shared 10 GiB, 10,000-file budget by default. Existing files are never overwritten, and nothing is deleted without permission.

capturefab storage

One process per camera

Each camera runs in its own worker with a shared-memory frame ring, so one stalled camera never blocks another.

status --json

Quickstart

A few commands to a frame.

No camera nearby? Use --camera sim:0 for the built-in simulator.

Open the desktop app

Run it with no arguments to discover cameras, preview them and inspect their settings.

capturefab

Discover cameras

Network, USB3 Vision and host cameras, as structured results for scripts.

capturefab discover --json

Read, configure, capture

Use a discovered ID, a unique serial or a GigE camera's IP address. Feature names vary by camera; features lists the available controls.

capturefab --camera 192.168.1.10 features
capturefab --camera 192.168.1.10 get Width Height ExposureTime
capturefab --camera 192.168.1.10 set ExposureTime=5000
capturefab --camera 192.168.1.10 capture -n 10 -o frames

Open a network stream

Use a stream URL directly, or resolve an ONVIF camera's profiles.

capturefab --camera 'rtsp://camera/live' capture -o frame.png
capturefab onvif discover --json
capturefab --camera 'onvif:http://camera/onvif/device_service' capture -o onvif.png

Use a host camera

List cameras managed by the operating system, then use the native locator.

capturefab native --json
# macOS
capturefab --camera avfoundation:0 capture -o webcam.png
# Linux, including driver-backed USB or CSI cameras
capturefab --camera v4l2:/dev/video0 capture -o webcam.png
# Windows
capturefab --camera 'dshow:video=Camera Name' capture -o webcam.png

Schedule a timelapse to a drive

Save a folder destination once, then capture into it on an interval.

capturefab destination add-folder usb "/Volumes/CAMDISK/Capturefab"
capturefab --camera sim:0 capture --interval 10s -n 360 -o timelapse --destination usb

Check this computer

Report compiled-in features, network interfaces, USB access and the JPEG engines this host can use.

capturefab doctor --json
Forward a camera to MediaMTX or an NVR

Publish to an existing RTSP server, SRT endpoint or a local video file. Automatic encoder selection probes usable hardware and falls back to software.

capturefab --camera 192.168.1.10 forward \
  --output rtsp://localhost:8554/camera \
  --encoder auto --fps 30 --bitrate 4M --duration 60

Automate

Keep the window open. Hand over the controls.

The desktop app exposes a local, token-authenticated session. Shell scripts and coding agents can inspect it, connect cameras, change features and capture frames while you watch.

capturefab sessions --json
capturefab --session gui status --json
capturefab --session gui connect 192.168.1.10
capturefab --session gui set ExposureTime=5000
capturefab --session gui capture -n 10 -o frames
capturefab schema --json

Unix conventions. Structured results on stdout, diagnostics on stderr, meaningful exit codes, pipes, native shell completions and headless sessions with serve.

Agent readable. A versioned schema and session API, plus instructions for Claude Code, Codex, OpenCode and any tool that can run a CLI.

Platforms

Wherever the camera is.

  • macOSApple silicon on macOS 11 and later, Intel on 10.15 and later. Host cameras through AVFoundation.
  • Windowsx64 on Windows 10 and later; Windows 11 on ARM runs it through emulation. Host cameras through DirectShow.
  • Linuxx64 and ARM64 with glibc 2.28 or newer. USB and CSI cameras through V4L2 drivers.
  • Jetson & PiThe Linux ARM64 build on Jetson Linux R34+ or a 64-bit Pi OS. Headless builds suit remote capture; 32-bit ARM builds from source.

The GUI renders with the GPU and falls back to software. Hardware video encoders and JPEG engines are used only when a real probe succeeds on the host, with a software fallback.

Tested on real hardware: Basler GigE cameras on macOS ARM64 and Jetson Linux ARM64, and a Logitech C920 webcam on macOS. USB3 Vision, ONVIF and Windows hardware are still validation targets. See the validation record.
