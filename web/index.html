Free, open-source (MIT) camera capture CLI

Camera capture for people, scripts and AI agents.

One capturefab command finds, configures, captures from and records GigE Vision and USB3 Vision cameras, webcams, RTSP/ONVIF streams and files. Every command can print one JSON document with a typed exit code, so an agent drives a camera in a few calls.

Download Capturefab ↓

curl -fsSL https://capturefab.com/install.sh | sh

Free and open source (MIT). macOS, Windows and Linux. See an agent session →

  • No vendor SDK, Aravis, libusb or FFmpeg to install.

Built for agents

Few calls, small results, clear errors.

Claude Code, Codex and other agents that run shell commands use Capturefab as it is. schema describes every command; each result is one JSON document; the exit code and error.code say what to do next.

# Not installed? Use the one-line installer above, or ./capturefab (.\capturefab.exe on Windows) from the extracted folder.

capturefab schema
capturefab list --json
capturefab inspect --json -c sim:0 --preview none
capturefab capture --json -c sim:0 -o 'shots/{seq}.png'

What it does

Measure, change, capture, record.

Each command does one job well and reports exactly what happened.

Measure before you capture

inspect measures exposure, clipping and focus on a fresh frame, suggests an exposure and writes a small preview.

Exposure and focus

Change settings safely

set writes several values as one change, in a valid order, and puts every value back if one fails. Portable controls work across vendors.

Read and change settings

Capture and record

Single frames, bursts, time lapses and triggered captures; H.264, HEVC, AV1 or lossless FFV1 video to files or streams. Files are never overwritten.

Capture imagesRecord video

Keep cameras open

--keep 5m keeps a camera open between calls; --background runs long captures and recordings as jobs; serve runs a session under systemd.

Install from a terminal

One command picks the build for this computer, checks its SHA-256 and installs it for your account, without sudo or administrator rights.

curl -fsSL https://capturefab.com/install.sh | sh
irm https://capturefab.com/install.ps1 | iex

The first line is for macOS and Linux, the second for Windows PowerShell. To read the script first: curl -fsSLO https://capturefab.com/install.sh; less install.sh; sh install.sh. Read install.sh or install.ps1.

Before you download

Which cameras can I connect?

GigE Vision and USB3 Vision (GenICam) cameras, webcams and capture cards, RTSP, SRT and ONVIF streams, and video files. Support depends on the device and operating system; this is an early implementation with less coverage than some vendor SDKs. Read the camera requirements and limits.

Do I need a vendor SDK or FFmpeg?

No. Downloads include FFmpeg for webcams, streams and video. You need the operating system's camera and USB drivers. USB3 Vision cameras on Windows must use WinUSB; the first-use steps say how. Read the installation instructions.

How does an AI agent use it?

Through the shell, like any command-line tool. Give your agent agents.md or let it run capturefab schema. Results are JSON, exit codes are typed, and each error has a code and a hint. Your agent decides what its model sees.

Windows says the program is unrecognized. Is that expected?

If a Windows download is listed as Unsigned, Microsoft Defender SmartScreen may warn the first time you run capturefab.exe. Check the SHA-256 checksum first, then choose More info → Run anyway, or use the PowerShell installer. The download list shows each file's signature.

How do I check that my computer is ready?

Run capturefab doctor. It checks FFmpeg, folders, GigE adapters and, on Linux, USB and network limits, and prints a fix for each warning. Read the checks and the troubleshooting guide.

Can I use Capturefab for commercial work?

Yes. Capturefab uses the MIT license. The separate FFmpeg executable uses GPLv3. Each release includes the corresponding source and license notices. Read the licensing details before redistribution.

Where is the desktop app?

Capturefab is now a command-line tool. Version 0.5.0 and earlier included a desktop app; keep 0.5.0 to go on using it. Read upgrading from the desktop app.

How do I verify a download?

The download selector shows a command with the file name and its SHA-256 filled in. Run it in your Downloads folder: it prints OK when the file matches. The install script checks the checksum before it installs anything. You can verify GitHub build provenance with gh attestation verify FILE --repo capturefab/capturefab.

Build Capturefab from source

Build requirements

Use a stable Rust toolchain, a C compiler and CMake. For x86 builds, NASM is also necessary for libjpeg-turbo. FFmpeg is necessary for webcams, streams and recording. Download the source code of a release. It includes every Rust dependency, so the build works offline. Read the FFmpeg build guide for configuration.

tar -xzf capturefab-VERSION-source.tar.gz
cd capturefab-VERSION
cargo --config .cargo/vendor-config.toml build --release --offline --locked
target/release/capturefab capture -c sim:0 -o first.png
