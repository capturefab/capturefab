Free, open-source (MIT) camera workbench

Industrial and network camera capture.

For manufacturing, process and vision engineers. GigE Vision and USB3 Vision are built in, plus webcams, RTSP/ONVIF streams and hub cameras. Captures are cataloged and export to Parquet or CSV, from the desktop app, scripts or AI agents.

Desktop and CLI in one session

See what your agent does.

Pin a named session and camera. Give the agent a recognizable name. Activity shows its actions, saved files and errors.

# Not installed? Use the one-line installer under Download, or ./capturefab (.\capturefab.exe on Windows) from the extracted folder.

# Open a named desktop session
capturefab gui --name bench

# Use another terminal for these commands
capturefab --session bench --actor capture-agent --actor-kind agent connect sim:0 --json
capturefab --session bench --actor capture-agent --actor-kind agent --camera sim:0 capture -o 'shot-{seq}.png' --json
capturefab --session bench status --json

Keep files and capture data together.

Save capture times and tags with each cataloged image. Use saved destinations to save files on your disk, removable drives or mounted network folders.

Build an image dataset in three commands

Capture tagged images into a DuckDB catalog, query it with SQL and export the tables for pandas, Polars or a notebook.

# Not installed? Use the one-line installer under Download, or ./capturefab (.\capturefab.exe on Windows) from the extracted folder.

# Capture 3 tagged images, 500 ms apart, into a catalog
capturefab --camera sim:0 capture -n 3 --interval 500ms --context part=A-100 --dataset parts.duckdb -o 'parts/{camera}-{seq}.png'

# Query the catalog with SQL
capturefab dataset query --file parts.duckdb "SELECT path, wall_ms, context FROM captures"

# Export Parquet and CSV tables with manifest.json and README.md
capturefab dataset export --file parts.duckdb -o export

Install from a terminal

One command picks the build for this computer, checks its SHA-256 and installs it for your account, without sudo or administrator rights.

curl -fsSL https://capturefab.com/install.sh | sh
irm https://capturefab.com/install.ps1 | iex

The first line is for macOS and Linux, the second for Windows PowerShell. To read the script first: curl -fsSLO https://capturefab.com/install.sh; less install.sh; sh install.sh. Read install.sh or install.ps1.

Before you download

Which cameras can I connect?

Capturefab supports GigE Vision, USB3 Vision, host cameras, network streams and other sources. Support depends on the device and operating system. This is an initial implementation with less feature coverage than some vendor SDKs. Read the connection guide and camera compatibility notes for device requirements.

Do I need a vendor SDK or FFmpeg?

No. Published downloads include FFmpeg for host cameras, streams and video encoding. You must supply the operating system's graphics, USB and camera drivers. USB3 Vision cameras on Windows must use WinUSB; the first-launch steps say how to set it and undo it. Read the installation instructions.

Windows says the app is unrecognized. Is that expected?

If a Windows download is listed as Unsigned, Microsoft Defender SmartScreen may warn the first time you open capturefab.exe. Check the SHA-256 checksum or the GitHub attestation first, then choose More info → Run anyway. The download list shows each file's signature.

How do I check that my computer is ready?

Run capturefab doctor from the extracted folder. It lists checks for the GPU, settings storage and capture efficiency. capturefab doctor --json adds compiled features and network interfaces. Read the troubleshooting guide for what each check means.

Can I use Capturefab for commercial work?

Yes. Capturefab uses the MIT license. The separate FFmpeg executable uses GPLv3. Each release includes the corresponding source and license notices. Read the licensing details before redistribution.

Does Capturefab send my images to a cloud service?

Capture saves images to files. Stream forwarding sends video to the receiver you configure. The assistant sends prompts and session details to the selected provider. Apple Intelligence runs locally and accepts text only. Other providers share images and dataset rows only with separate permission.

Prompt-driven video analytics sends sampled images when you start collection. External agents control their own data sharing. Read about the assistant, destinations and video analytics.

Can a script control an open desktop session?

Yes. Camera commands automatically use the only desktop or headless session that is open. Use capturefab sessions to list sessions. Use --session NAME to select one when several sessions are open. Read about sessions and automation.

Where are captures saved, and what happens at the storage limit?

The desktop app saves to a Capturefab folder in your home folder by default. CLI output names are relative to the terminal's current folder. Add a saved destination to use another folder or drive. Capturefab never overwrites an existing file.

At the storage limit, Capturefab stops capture or recording. It returns exit code 6 and a message that identifies the limit. Capturefab disables automatic deletion by default. --delete-oldest permits deletion of unchanged Capturefab files.

How do I verify a download?

The download selector shows a command with the file name and its SHA-256 filled in. Run it in your Downloads folder: it prints OK when the file matches. The full download list has the same command under each build, and the install script checks the checksum before it installs anything. You can verify GitHub build provenance with gh attestation verify FILE --repo capturefab/capturefab.

Upgrading from 0.3 or earlier?

Version 0.4.0 removed built-in S3, FTP and SFTP uploads and signal sources. Read the upgrade notes before replacing an existing installation.

Build Capturefab from source

Build requirements

Use a stable Rust toolchain, a C compiler and CMake. For x86 builds, NASM is also necessary for libjpeg-turbo. FFmpeg is necessary for webcams, streams and recording. Read the build guide for configuration.

git clone https://github.com/capturefab/capturefab
cd capturefab
# Desktop app and CLI
cargo build --release
# Headless CLI
cargo build --release --no-default-features --features usb,jpeg
target/release/capturefab --camera sim:0 capture -o first.png
